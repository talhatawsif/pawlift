# PawLift

You're already going somewhere. You might be able to help an animal get there too.

Animal rescue transport coordination, starting in Western Melbourne.

## Develop

```bash
npm install
cp .env.example .env.local   # fill in values; never commit it
npm run dev
```

Checks: `npm run lint` · `npm run typecheck` · `npm test` · `npm run build`

See `CLAUDE.md` for project rules and `docs/` for the brief and plan.
